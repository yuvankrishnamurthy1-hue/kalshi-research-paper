SNAGS (with reasons)
--------------------
1. VM reboot killed run 1 (~04:28 UTC, mid batch-A1). Reason: host restart,
   /tmp wiped (run log lost). Restarted immediately; resumed from the 185
   surviving raw ticker files. No data loss — the collector re-fetches any
   window the cache cannot fully cover.
2. Historical-endpoint schema mismatch (CAUGHT AND FIXED). Kalshi's
   /historical candlesticks use close/volume/open_interest keys; the live
   endpoint uses close_dollars/volume_fp/open_interest_fp. The inherited
   parser read only the live keys, so all 240 historical event-ticker pairs
   came back price-less (8,818 empty rows). Fixed with a dual-schema parser
   (px_field) and re-ran the full pull. Final CSV: 0 price-less rows.
   *** ALSO AFFECTS THE SUMMER PULL: 17 tickers / 176 rows in
   kalshi_api_data_summer/market_data.csv (candle_source=historical) are
   fully empty for the same reason. Summer files were NOT modified (out of
   scope); the analysis should either re-parse those raw files with the
   dual-schema reader or treat the 176 rows as missing. ***
3. Batch C dates unverified. browser_search was down (401 credential
   expired) at pull time, so: NBA draft lottery = 2026-05-11 approx
   (standard mid-May timing; candidate_events.md lists lottery in May),
   MLB All-Star Game = 2026-07-14 approx (no date in brief). NBA draft =
   2026-06-24 per brief. If exact dates matter, re-verify and shift T0 —
