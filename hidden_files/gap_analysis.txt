GAP ANALYSIS — Kalshi summer pull (collection 2026-09-23, run 6)
Generated 2026-09-23. Source: kalshi_api_data_summer/collection_log.json + market_data.csv.

1. WHAT "GAPS" ARE
The 956 gaps in collection_log.json are ticker-level, not day-level: each gap is
an (event, ticker) pair for which NO candles were fetched for that event's
[T-45, T+10] window (fetch failed with URLError/IncompleteRead/RemoteDisconnected
after retries). All 956 gap tickers DO have candle data from other events'
windows — the tickers exist and trade; the failure is in our collection, not the
market. Missingness is therefore a property of fetch batches, not of liquidity.

2. DAY-LEVEL COMPLETENESS (separate issue, more important)
For still-open (unsettled) contracts the Kalshi live candlesticks endpoint
returned only recent history (e.g. KXFED-27APR-T4.50: 5 candles, 2026-09-19..24;
KXCPICORE-26SEP-T0.5: 26 candles from 2026-08-29). This is consistent with those
contracts having been LISTED recently (Kalshi lists new Fed/CPI expiries as old
ones settle — e.g. post-Sept-16-FOMC), i.e. the history genuinely does not
exist. Settled/settling series (KXCPI-26SEP, KXFED-26SEP) returned full windows
via the historical endpoint.
Consequence: many (event, ticker) pairs have <5 baseline observations and are
excluded by the analysis script (insufficient_baseline_history), independent of
the 956 fetch gaps.

4. IS THE MISSINGNESS RANDOM?
- The 956 fetch gaps: bucket distribution of gaps vs fetched is roughly uniform
  across strikes within an event (e.g. hormuz_strike gaps span T-0.1..T6.00 in
  similar proportions to fetched), and gap expiries overlap fetched expiries.
  Verdict: approximately random conditional on (event, series) — driven by
  timeout bursts during specific fetch batches. Not obviously correlated with
  price outcomes. Benign for event-level means.
- The newly-listed-contract exclusions: SYSTEMATIC. Missingness correlates with
  contract tenor (far-dated Fed/CPI contracts listed recently). The analyzable
  sample for the Sept 11-16 macro events is selected toward near-term/settling
  contracts. Near-term buckets are the most reactive (and the economically
  relevant ones for CPI/Fed news), so event-level abnormal-move estimates remain
  interpretable, but (a) H3 tier-gradient tests for macro are compromised —
  tail buckets (M2/M3) are underrepresented; (b) cross-event comparability of
  "the macro market reaction" is weakened because different events are measured
  on different contract sets.
- Overlap/contamination (separate from missingness): the Sept 8-16 macro
  cluster shares contracts and [T-45,T+10] windows overlap heavily (468 of 483
  tickers appear in >1 event). Baseline windows for later events contain earlier
  events' windows. The analysis script's placebo contamination exclusion and
  the prereg's disclosure cover this partially; recommend an additional
  robustness check dropping events whose baseline contains another event's T0,
  or narrowing baselines — documented in prereg_deviations.md.
